# hacktoberfest-2026

Small open-source AI projects, each built for a real person, made during Hacktoberfest 2026.

Every project runs on open-weight models, open-source frameworks or local inference.

## Projects

| Project | Built for | What it does | Status |
|---|---|---|---|
| [Reel](reel/) | A movie and series fan | Telegram bot that tracks what you watch and suggests what to watch next | Built |

## Layout

Each project lives in its own folder and is self-contained: its own dependencies, README, `.env.example` and tests.

```
hacktoberfest-2026/

└── ...          # more projects to come
```
